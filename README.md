# Kapaleshwar Mahadev Temple Website

Angular static website prototype for Shri Kapaleshwar Mahadev Temple, Derapur, Kanpur Dehat.

## Requirements

- Node.js compatible with the installed Angular CLI
- npm

## Run locally

```bash
npm install
npm start
```

Then open the local URL shown by Angular CLI.

## Production build

```bash
npm run build
```

The production output is generated under `dist/kapaleshwar-temple/`.

## Deployment direction

The project is designed for static deployment, such as Cloudflare Pages.

## Important content note

This is a prototype. Historical, location, timing, contact, social-media, donation and other official information should be verified before publication.

See `CONTENT-VERIFICATION.md`.

## Images

The current images are SVG placeholders. Replace them with authorized official temple photographs in:

`src/assets/images/`

Do not use copyrighted images from Google, YouTube or other websites without permission.
